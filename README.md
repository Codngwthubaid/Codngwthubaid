## 👨‍💻 About Me

I'm a **Data Engineer in the making**, currently working as an **Associate Analyst at AML RightSource (AMLRS)**, where I work hands-on with financial data every day — cleaning, reconciling, filtering, and analyzing customer records with **Excel and SQL** to support accurate reporting and data review.

My path into data started with **full-stack web development**. I shipped production features as a developer intern at two digital studios (MERN, React, React Native, HonoJS) and spent 1.5+ years teaching web development to international students on **Preply** (165+ classes, 4.3/5★ rating). That engineering foundation — APIs, databases, clean code, and relentless debugging — is exactly what I'm now channeling into **data engineering**.

Today I build end-to-end pipelines with **Python, SQL, PySpark, dbt, Apache Airflow, Kafka, and Databricks**, including a lakehouse project that ingests raw data with **PySpark Structured Streaming** and models it through a **Medallion (Bronze → Silver → Gold)** architecture with **dbt**.

- 🔭 **Currently building:** end-to-end ETL/ELT pipelines on Databricks (PySpark + dbt + Delta)
- 🎯 **Career goal:** become a Data Engineer who turns raw, messy data into reliable, analytics-ready datasets
- 🌱 **Currently learning:** streaming architectures, workflow orchestration at scale, and lakehouse design patterns
- 🧠 **What I bring from my dev years:** API design, data modeling, and performance optimization — now applied to data platforms
- ⚡ **Fun fact:** I've debugged more web apps than I can count — now I debug data pipelines instead
